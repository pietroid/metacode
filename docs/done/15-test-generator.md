# 15 — Test Generator

## Goal

Generate widget and Cubit tests from the behavior scenarios so that `flutter test` can verify the generated app.

## Scope

- For each behavior scenario, generate a test that encodes the assertion.
- Generate two kinds of tests:
  - **Cubit tests** for store actions (using `blocTest` when `when` targets a store action).
  - **Widget tests** for UI behavior and rendering (using `WidgetTester` when `when` targets a UI event or is empty).
- Tests should:
  - Set up the `given` state (e.g. provide a Cubit with a seeded state).
  - Perform the `when` action (e.g. tap a button, call a cubit method).
  - Assert the `then` condition (e.g. verify state value, find text on screen).
- For the counter app:
  - Cubit test: `increment` changes value from 2 to 3.
  - Widget test: tapping the button increments the displayed value.
  - Rendering test: value 5 is displayed.

## Acceptance criteria

1. Counter app behaviors produce at least one Cubit test and one widget test.
2. Generated tests import the correct generated files.
3. Generated tests are syntactically valid Dart and compile.
4. Unit tests verify generated test strings contain expected assertions.

### Example generated widget test

```dart
// GENERATED BY METACODE - DO NOT EDIT BY HAND
// Source spec: behaviors.yaml > When button is tapped, increment counter

import 'package:flutter/material.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:counter_app/pages/home_page.dart';
import 'package:counter_app/stores/counter_cubit.dart';

void main() {
  testWidgets('When button is tapped, increment counter', (tester) async {
    final cubit = CounterCubit();
    await tester.pumpWidget(
      BlocProvider.value(
        value: cubit,
        child: const MaterialApp(home: HomePageWrapper()),
      ),
    );
    await tester.tap(find.byType(FloatingActionButton));
    await tester.pump();
    expect(cubit.state.value, 1);
  });
}
```

## Layering notes

- Depends on: IR, behavior parser, planner, deterministic generators.
- Enables: flutter test runner and TDD fix loop.
- Generated tests are deterministic. They should target the wrapper layer, not the dumb widgets, because the wrappers encode the behavior wiring.
- Keep test generation simple for the MVP. Parameterized/grouped tests are deferred.
