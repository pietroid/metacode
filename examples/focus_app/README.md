# Focus App

A task list, generated by Metacode. It exercises what `counter_app` does not:
a model (`models.yaml`), a store holding `list(task)`, a dynamic list with one
row per element, a checkbox inside each row that toggles its own task, and a
page that swaps between an empty state and the list.

```bash
cd examples/focus_app
go run ../../engine/cmd/metacode run
flutter test
```

The specs are in `metacode/`. Everything under `lib/` and `test/` is generated:
read `metacode/behaviors.yaml` first, then compare it with `test/`.
